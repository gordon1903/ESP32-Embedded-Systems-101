# ESP32-Embedded-Systems-101
A hands-on journey of the author learning ESP32 starts from "Hello World!" to a typical 2WD Mobile Robot<br/>
<br/>
Hardware:<br/>
ESP32 DevKit V1-style development board<br/>
- Module: ESP-WROOM-32 family<br/>
- Pin configuration: 30 pins (15 per side)<br/>
- USB connector: Micro USB<br/>
- Buttons: EN (Reset) and BOOT<br/>
- Logic voltage: 3.3 V<br/>
- Programming: USB-to-UART interface<br/>
